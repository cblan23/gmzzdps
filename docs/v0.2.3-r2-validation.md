- `damage_hook.py`：治疗玩家没有对 Boss 造成伤害时，也能通过已捕获的 Boss 入伤事件触发原有的一次性组件补读，恢复中途启动漏掉的 Boss 模板。继续使用原 Hook 链路；没有增加游戏请求，也没有改用 Npcap。
