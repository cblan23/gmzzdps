按最新要求重新设计为深色。三个页面、全部现有设置与快捷键状态均可交互；这是设计交付，正式 Tk 设置界面尚未替换。

## 版式

- 720 × 650 的单列窗口，顶部仅保留品牌、标题与三个分类。
- 炭灰底色、细分隔线、低饱和紫色选中状态。去掉侧栏、分组卡片与右侧说明区。
- 首屏六项常用显示设置，其他选项折叠；底部固定保存状态与恢复默认值。
- 外观页有明确标为示例的窗口预览，字体、缩放与行遮罩可即时试用。
- 快捷键页包含录入、取消、清除、重复提示、解锁前置条件和折叠帮助。

## 现有功能对应

| 页面 | 设置 |
| --- | --- |
| 显示 | 玩家名称、对应总量、死亡次数、全队秒伤、本人高亮、首领血条 |
| 更多显示选项 | 战斗时间、PvP 按钮、战前非凡评分预览、狂暴节奏预测、观众 HPS / DPS、战士 DPS / DT |
| 外观 | 字体 12–18 px、主窗口缩放 80–140%、玩家行遮罩 0–100% |
| 快捷键 | 显示 / 隐藏、仅快捷键解锁、同一快捷键锁定 / 解锁 |

功能清单对应 `dps_meter.pyw` 的 `_build_backend_settings_page`。预览仅使用独立的本页存储，不写入软件配置；旧浅色稿保存在本地临时备份中。
