## 网页快速恢复（12:11 更新）

已新增“快速恢复”：在线且连接正常时只检测；QQ 在线但发卡未连接时重启固定发卡服务并等待真实连接上报；QQ 离线或登录服务不可达时正常重启现有容器（不删除 Session、卷或领取记录），等待 WebUI 启动，再请求新二维码并验证 URL 与请求前不同。最多等待 25 秒确认二维码变化，不能确认则失败并提示，不显示缓存旧码。

确认生成的二维码在页面最多展示 90 秒；这是保守展示期限，不承诺 QQ 服务端实际有效期。登录错误、地址变化或操作进行中立即隐藏二维码，不通过 GET 隐式触发登录或重启。

扫码后维护观察器检测真实 OneBot online，再确认发卡 worker 的新鲜上报（PID、时间、在线状态）；必要时启动/重启发卡服务。最后检查发卡 API，只有检查通过才报告恢复完成。等待扫码时不阻塞管理员刷新二维码；运行中的操作互斥，同 request_id 重试不重复执行。

维护会话在服务器内缓存50分钟、鉴权失败有退避，避免每次刷新再次请求 auth/login。容器重启后失效会话清理。二维码仅以 PNG data URL 提供给已认证管理员，不返回管理 Token。
