## 恢复范围与验收边界

- 自动恢复严格要求当前登录角色与档案角色一致，只处理关卡 `5150095`、模板 `7110208`、结束原因为 `space_transition` 且终点血量在 0 到最大血量 2% 之间的旧档案。
- 恢复沿用原战斗 ID，保留原始终点血量证据，将档案修正为确认胜利后自动补传。服务端用真实档案整体替换对应的服务器时钟占位记录。
- 当前网页场次 `enc_qrtzJYcpYwa-GB8b61ouuIR6` 仍显示 `RECOVERED_CLOCK_ONLY` 和 `PARTICIPANT_METRICS_MISSING`。月眠川原电脑安装并启动 v0.3.6d、识别到该角色且完成原始档案补传后，才可验收真实个人伤害、DPS、HPS、技能和时间轴。
- 本次自动化、构建、CDN 和在线更新验收不能替代月眠川原电脑上的档案存在性、登录后的自动补传和网页最终结果验收，因此 GitHub Release 保留预发布标记。
