## 修改

实时官方统计的伤害与分母使用同一份 Common 回包：

`累计有效战斗秒数 + 当前服务器时间 - 当前活动阶段起点`

当前服务器时间通过本地采集时间加动态时钟偏移计算。成员处于暂停状态时，只采用已经累计的秒数。

- 小怪 HUD 使用官方统计时间，修正本地计时起点偏晚及中途开始采集的问题。
- 实时官方行按成员自己的计时字段计算，并按完整团队快照刷新。
- 日常副本保留累计伤害时，使用对应累计时长；副本重新开始计数时，采用新的伤害计数和起点。
- Boss 顶部计时仍表示这次 Boss 战斗经过的时间；实时官方 DPS 的分母来自游戏统计表。
- 缺少可用官方时钟的情况保留原有本地投影。
- 修正终场快照继承旧活动起点、导致累计时长重复相加的问题。
