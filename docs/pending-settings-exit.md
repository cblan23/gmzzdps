# DPS 窗口点击设置后偶发全部窗口退出

用户反馈：在 DPS 窗口状态下点击设置，有概率直接退出全部窗口。

反馈编号：`FBE6556EF15B3BE2FF`，来自 `0.2.3+20260911.2`。

状态：v0.2.3b 打包完成后已排查，并修复源码中的窗口消失风险；本条尚未纳入该包。

优先区分：实际进程崩溃、主线程异常退出，还是窗口被隐藏/最小化。检查异常日志、反馈诊断、点击回调以及主窗口与设置窗口的切换流程。尚未确认根因。

反馈没有异常堆栈，不能确认实际进程崩溃。代码中可复现的风险是：先隐藏主窗口，后展示设置；展示失败时没有恢复。另有 `focus_set()` 不主动激活应用，可能让设置留在游戏后方。

源码调整：设置切换延迟至点击回调结束；重复点击合并；确认设置已映射后才隐藏主窗口；主动聚焦但保留原置顶设置；失败时恢复主窗口并记录错误。

验证：3 项针对性测试及 30 次真实 Tk 窗口切换通过。对原反馈是否属于原生崩溃仍需用户复测/异常日志验证。
