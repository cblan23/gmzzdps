# 木桩秒伤出现超大数值

用户提供截图：木桩秒伤和累计伤害出现接近 64 位整数边界的异常值。目前尚无该个例的反馈编号或原始日志，不能从截图确认唯一来源。

源码已补充保护：

- 原始伤害事件和队伍累计计数拒绝负数、非数值、非有限值以及超出有符号 64 位范围的金额。
- 对异常累计字段跳过本次更新，保留上一份有效数据；不把异常转成 0，不触发错误重置。
- 同一条队伍快照的有效承伤/治疗和其他队员仍正常处理。
- 下一份有效累计可以正常接续；原始消息仍保留于采集日志。
- 运行诊断新增 `invalid_combat_values` 计数，方便后续反馈定位。

回归覆盖无符号回绕值、木桩 RPC、直接伤害事件、异常累计后的有效快照，以及正常大额累计。

该改动在 v0.2.3b 打包后完成，尚未进入新的正式包。未更改预警条或双 Boss 预测逻辑。
