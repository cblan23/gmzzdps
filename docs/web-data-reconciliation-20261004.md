## 原因与修复

- 客户端历史把伤害成员保存在 `participants`，把治疗成员与治疗技能保存在 `healers`。旧上传转换只读取前者，导致网站虽有团队治疗汇总，个人治疗与技能详情仍为空。
- 上传转换现按角色 ID 合并两张表，保留有效治疗、HPS、总治疗、过量治疗、治疗技能次数和技能明细。沿用客户端显示规则，过滤已确认非治疗职业的旧治疗行。
- 服务端清洗并保存新增字段，旧客户端重复上传同场时会保留已补齐的治疗详情。网页治疗模式按有效治疗列出技能及对应详情。
- 修正服务端战斗时钟与抓包起止时间不一致时的上传时间；同一队友被两个采集 ID 重复记录且职业、伤害一致时只上传一次。
- 客户端上传界面显示已捕获姓名，不再提供匿名选择；没有捕获到的姓名在网页标为“未记录姓名”。
- 排行榜改用战斗详情相同的姓名规则；旧记录缺少可恢复姓名时显示“未记录姓名”，不再显示“匿名玩家”。
- 旧版客户端每次上传只附带上传者本人的姓名，队友姓名字段留空；如果本人姓名当时也没采集到，这次上传连本人姓名也没有。新版上传转换会附带本场已采集到的所有成员姓名。同一场有多人分别上传时，旧记录也可能显示多个姓名。
