# BOSS 头像素材

本目录保存从本机 C7 客户端 `2018737` 原始资源中解码出的头像。客户端文件未被修改。

## 覆盖范围

- `boss_icon_sources.json` 收录 32 个 `DungeonData`、27 个副本入口和 101 个 `StageData` 关卡。
- 101 个关卡引用的 33 张唯一头像均已提取；另保留安西娅、巴尼先生的 2 张客户端伙伴头像和 1 张客户端木桩图标，共 36 张 PNG。
- 当前程序识别的 84 个 BOSS/机制模板中，83 个有可靠图片映射。
- 当前 `combat_history/` 中出现的所有 BOSS/机制模板均已映射，`unmapped_template_ids` 为空。
- 10 个训练/测试木桩共用客户端 `Interact_WoodenMan` 专用图标。仅任务首领“梦境捕手”仍无图：客户端未给它配置 `StageIcon` 或 `HeadInfoIcon`，清单明确标为 `unavailable`，不会用无关图片冒充。

## 查找顺序

1. 有 `template_id` 时查 `bosses`，这是当前应用识别目录的确定映射。
2. 未在 `bosses` 中时查 `client_stage_templates`，用于尚未进入应用静态目录、但客户端已有唯一关卡头像的模板。
3. 有 `stage_id` 时直接查 `stages`，可消除同名关卡的歧义。
4. 只有名称时查 `stage_name_index`；如果返回多个候选，必须再结合 `stage_id` 或 `dungeon_id`，不能任取一张。

同一 BOSS 的普通/困难模板通常共用一张客户端原图，因此“每个模板可确定查到头像”不等于“每个模板拥有不同图片”。`confidence` 字段说明映射类型：

- `direct`：客户端关卡直接配置的专属头像。
- `stage_shared`：不同难度、阶段或角色共用客户端关卡头像。
- `encounter_auxiliary_shared`：机制目标沿用所属 BOSS 头像。
- `candidate`：客户端没有独立 BossHead，使用已核实的同角色伙伴头像。
- `client_ui_shared`：没有 StageIcon，但使用客户端为该目标类型制作的专用 UI 图标。
- `unavailable`：客户端没有可确认的独立头像。
